# Repository Map Capability

This crate constructs bounded, deterministic, Git-aware repository inventories and deep repository-comprehension views from immutable evidence supplied through approved host boundaries. It parses only the exact pinned v0.1 language set, preserves unsupported and excluded paths as visible coverage states, emits hash-bound source ranges and reliable syntax relationships, resolves every retained structural fact to exact parser and Git evidence, and renders conservative token-bounded context slices with explicit `Unknown/Blocked` lexical fallback.

Deep analysis adds source-resolvable profiles, facts, traces, blind spots, branch-aware history and portfolio views, bounded slices, and structured learning exports. Change planning derives hash-bound intent, minimal impact, reproduction, hypothesis, regression, alternative, review, and validation records from that evidence. Repository instructions are retained as untrusted evidence and explicitly rejected as planning authority. The capability has no filesystem, process, credential, model, network, or mutation authority. Its SQLite cache is disposable and in-memory in this increment; production persistence, host projection, citation orchestration, and platform integration remain separately gated work. Filesystem and Git operations exist only in a terminal test module that builds disposable invariance fixtures and is excluded from product-effect surfaces. See [`deep-repository-comprehension.md`](../../docs/architecture/deep-repository-comprehension.md) and [`change-intent-and-planning.md`](../../docs/architecture/change-intent-and-planning.md) for the complete boundaries.
