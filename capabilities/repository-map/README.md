# Repository Map Capability

This crate constructs bounded, deterministic, Git-aware repository inventories from immutable evidence supplied through approved host boundaries. It parses only the exact pinned v0.1 language set, preserves unsupported and excluded paths as visible coverage states, emits hash-bound source ranges and reliable syntax relationships, resolves every retained structural fact to exact parser and Git evidence, and renders conservative token-bounded context slices with explicit `Unknown/Blocked` lexical fallback.

The capability has no filesystem, process, credential, or network authority. Its SQLite cache is disposable and in-memory in this increment; production persistence, host projection, citation orchestration, and platform integration remain separately gated work. Filesystem and Git operations exist only in a terminal test module that builds disposable invariance fixtures and is excluded from product-effect surfaces.
