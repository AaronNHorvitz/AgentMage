# Repository Map Capability

This crate constructs bounded, deterministic, Git-aware repository inventories from immutable evidence supplied through approved host boundaries. It parses only the exact pinned v0.1 language set, preserves unsupported and excluded paths as visible coverage states, and emits hash-bound source ranges and reliable syntax relationships.

The capability has no filesystem, process, credential, or network authority. Its SQLite cache is disposable and in-memory in this increment; production persistence and host integration remain separately gated work.
