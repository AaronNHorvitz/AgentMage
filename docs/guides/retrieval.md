# Retrieval Guide

Deterministic lexical and metadata retrieval is the baseline. It preserves source ranges, hashes,
freshness, authority class, score factors, conflicts, omissions, and evidence state. A generated
answer cannot cite material outside its admitted retrieval envelope.

Optional semantic retrieval is local, opt-in, separately indexed, resource-bounded, deletable, and
non-authoritative. It may improve ranking but cannot create source facts, relax policy, use a
remote embedding service, or change completion evidence. Reopen current canonical sources before
making a material claim.
