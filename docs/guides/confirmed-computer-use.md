# Confirmed Computer Use

Computer use is a local visible fallback only when the exact structured operation is unavailable or
unsupported. Every action binds the foreground application and window, before screenshot,
coordinates, visible control, payload, precondition, single-use grant, and action identity.

Submit, upload, send, and every other external state change require a separate current confirmation
digest. A preview grants no authority. Completion requires a changed after screenshot, exact
application-state digest, confirmed single effect, and terminated owned work. Uncertain outcomes
stop for reconciliation and are never blindly repeated.

This contract captures no screen, controls no application, and performs no effect. Native capture,
accessibility, focus-loss, popup, stale-screen, cancellation, crash, and privacy campaigns remain
required before computer-use support can be claimed.
