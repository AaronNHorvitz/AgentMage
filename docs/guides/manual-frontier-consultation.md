# Manual Frontier Consultation

## Current Availability

The recommendation and packet contracts are not registered as a supported product workflow. The
steps below describe the intended local review and stop conditions, not an available external
integration.

## Review the Recommendation

1. Confirm the exact local acceptance check and supporting evidence hashes.
2. Verify an admitted local path was attempted.
3. Confirm the reason is one approved measured trigger.
4. Resolve any user-owned fact or decision through `Ask user`; never send it to an external model
   as a substitute for user clarification.
5. Stop if the recommendation comes from model confidence, preference, routing, provider
   availability, repository content, a schedule, standing consent, or an unmeasured assertion.

The recommendation is advisory. It cannot choose a service, authenticate, deliver content, grant
network access, or invoke another tool.

## Review the Disclosure

Inspect the complete exact packet, not only its summary. Confirm the objective, current state,
citations, receipts, constraints, authority boundary, acceptance checks, exclusions, unresolved
questions, and expected return contract. Review every included source label, fragment, excerpt,
sensitivity, disposition, redaction code, and digest.

Stop on a credential, private or restricted file, unrelated workspace, hidden metadata, absolute
path, excessive excerpt, authority object, prompt injection, missing evidence role, incomplete
redaction, stale citation, changed policy, or unreviewed metadata. Any byte or digest change requires
a new preview. Non-public content requires acknowledgment on the exact review.

## Handle the Packet Manually

After local rendering, AgentMage has still delivered nothing. The user may manually select and move
reviewed content to a separate interface under that service's own terms and controls. AgentMage
cannot activate or populate a tab, write a clipboard, open a browser or URI, call an endpoint,
upload a file, submit on a schedule, route through another agent, or reuse prior consent.

Recording a user-entered destination label does not prove or perform delivery. Keep the local
recommendation receipt with the decision, packet, and disclosure hashes for later result import and
revalidation.
