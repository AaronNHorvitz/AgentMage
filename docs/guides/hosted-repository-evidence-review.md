# Hosted Repository Evidence Review

Require a full immutable source identity for every fact. Reject branch-only URLs, absolute or
traversing paths, inconsistent repository/revision identities, missing retrieval time, secret
values, content authority, or state changes. Treat pagination, missing permissions, inaccessible
families, and local-revision mismatches as explicit incomplete coverage. Local contract results do
not substitute for a credentialed hosted/local comparison or native hostile-content campaign.
