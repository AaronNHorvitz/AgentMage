# Common Artifact Receipt Review

Use the Sprint 67 receipt only for observations already produced by a separately authorized
operation. Confirm the implementation and profile hashes, ordered input/output references, locator
coordinate system, fidelity disposition, limitations, unsupported features, invariance, cleanup,
and effect observations before recomputing the self-digest.

For audio, also confirm that the exact engine and codec were admitted locally, time ranges are
ordered and within the source duration, inferred speakers carry uncertainty, unclear language stays
explicit, and the original-audio retention disposition matches the approved plan. The validator is
not a transcription engine and a structurally valid observation is not accuracy evidence.

Reject stale hashes, duplicate or unordered identities, impossible locators, hidden effects, exact
fidelity with limitations, limited fidelity without a limitation, or any attempt to use local
contract tests as a native-platform, model-quality, accessibility, or release result.
