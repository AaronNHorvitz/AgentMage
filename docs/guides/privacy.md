# Privacy Guide

Classify content before persistence, indexing, model context, logging, or export. Highly restricted
knowledge cannot enter canonical Markdown. Secrets, credentials, hidden prompts, unrelated private
text, and unapproved excerpts cannot enter portable evidence bundles.

Use strict-local storage for encrypted operational records and archives. Keys remain behind the
platform secret adapter. Review exact disclosure bytes before creating an export. Local creation
does not imply permission to transmit an artifact or approval by any outside organization.
