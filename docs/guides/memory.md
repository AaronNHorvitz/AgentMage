# Memory Guide

Working memory is bounded session continuity, not evidence. Durable memory is user-reviewed,
source-backed Markdown with explicit scope, type, privacy, retention, and lifecycle status.
Candidate extraction alone does not promote memory.

Review source links before admitting, superseding, expiring, revoking, exporting, or deleting an
eligible item. Revoking a source withdraws every item of the workspace that cites it from loading. Reopen current sources when memory is stale or conflicts with evidence. Restricted content
and secrets remain outside portable Markdown memory.
