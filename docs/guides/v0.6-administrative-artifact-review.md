# v0.6 Administrative and Artifact Review

The v0.6 local bundle joins the canonical-record, briefing, meeting, task, correspondence, deadline,
document-control, privacy, extraction, generation, redaction, and verification guides. Reviewers must
use the exact Sprint 54–68 source-bound reports and the cross-format matrix; a local structural result
never substitutes for native render, accessibility, model, platform, or independent review evidence.

Administrative drafts remain user-controlled. Sending, live calendar mutation, messaging, external
database access, automatic recipient selection, and unattended disposition are disabled. Generated
or edited outputs remain proposals until their separately authorized controlled-write path completes,
and factual projections retain content-addressed evidence.

`G-V0.6` remains blocked while any source sprint is blocked, any format lacks its declared native or
accessibility evidence, any privacy/fidelity threshold fails, or a signed independent gate decision
is absent. Supported format count, supported platform count, and release approval therefore remain
zero, zero, and false.
