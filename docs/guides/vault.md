# Vault Guide

Obsidian is an optional view over the same canonical knowledge contract used by a plain folder.
The user selects one admitted local vault scope. AgentMage parses supplied immutable Markdown
snapshots, frontmatter, headings, tasks, tags, links, embeds, blocks, callouts, and timestamps into
a disposable index.

Ambiguous links, stale files, denied attachments, and parser coverage gaps remain visible. The
index can be deleted and rebuilt from the vault. AgentMage v0.2 does not open ambient paths,
execute note instructions, start an operating-system watcher, or write vault files.
