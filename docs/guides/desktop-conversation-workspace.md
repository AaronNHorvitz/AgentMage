# Desktop Conversation and Workspace Guide

Sprint 76 provides an effect-free source contract for a future local desktop surface. It is not an
installable or supported desktop application.

Conversation navigation can narrow by local date, workspace, project, exact model profile, tag,
status, pinned state, and archived state. Pinned results appear first, then newer updates. Transcript
projections distinguish Markdown, links, tasks, backlinks, previews, citations, tool observations,
approval prompts, errors, checkpoints, and branches without making those labels executable.

Open, continue, branch, rename, archive, export, and delete are displayed as kernel-request-bound
previews. Delete requires an explicit approval. Exact-diff, command, write, and delete approval
screens show the target and bind the preview and current policy; an approval claim is invalid
without an existing grant identity. The display never applies the effect.

Checkpoint comparison shows which of files, instructions, repository, model, permissions, and next
action changed. Workspace selection requires an explicit user selection and relative path
components. Absolute paths, parent traversal, hidden path authority, and an Obsidian dependency are
excluded.

If a request, digest, grant, path, date, or identity is malformed, the projection fails closed. Use
the existing CLI or native Chat source contracts for other presentation testing. Native desktop
packages, accessibility claims, clean installation, and platform support remain unavailable until
their exact external evidence is retained.
