## Change

The review fixes change the following:

- A trusted whole-file replacement edit, which no proposal can carry, now serves
  selected writes and rollback inverse writes. It is bounded by the file limit, not
  the single-edit limit. The host binds a derived write before it answers, so a
  selection it cannot write is refused cleanly.
- The one dispatch site uses the request's own immutable proposal class, and the
  Story 23.4 check refuses any rebinding.
- The engine refuses derived calls to tools a model may propose. It ends the run on
  a model proposal of an unoffered tool or a reserved call identity, before any
  budget is used.
- Other fixes cover:
  - long selection lines, which are now refused and asked again;
  - a cancellation entry kept in the job ledger;
  - an outcome-dependent notice to the model;
  - pure tests of the Linux narrowing derivation.

After each run the development CLI now shows the host's declarations about that run:

- Which of its effects a fresh approved inverse write could restore, and which need
  reconciliation. The Linux boundary builds this from its own execution and
  change-record records.
- A content-free view of each context the model received.

The CLI verifies the declaration's seal, run scope and summaries. Anything the host
cannot declare completely is shown as unavailable.
