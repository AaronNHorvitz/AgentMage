## Change

The review fixes:

- F1: the CLI keeps a route receipt only when its selected route is the person's profile, the
  candidate digest is that profile's canonical digest and the policy digest is the fixed local-only
  policy.
- F2: the suspension fixture's factory hands over the store-backed run action histories. Service
  tests show three things. A run started again after its host ended marks its stored job control
  chain incomplete and declares none. A suspended run whose host ends keeps its chain open. A
  continuation in the same host stores through its own handle.
- F3: the exact-word answer to a support bundle preview is a tested function of the read line.
- N4: a run resumed after a restart whose chain was never stored begins the chain marked incomplete.

AMR-05.9.5 is split into AMR-05.9.5.1 (documentation packs), AMR-05.9.5.2 (a language server
adapter) and AMR-05.9.5.3 (recipe plans). For AMR-05.9.5.1:

- The knowledge component exports a catalog's state and restores a catalog from one, re-checking
  every rule an import, retention or deletion checks. It searches kept packs through the
  deterministic retrieval.
- Operational store migration 23 keeps one documentation catalog: versions, files, deletion records
  and a head over the catalog state. Its triggers let a version only become superseded, keep files
  unchanged, remove a version and its files only with a later deletion record naming it, keep
  deletions append-only in sequence and move the head only forward. The kernel store commits each
  next state under the revision it read and checks the state at every store open and every load.
- The development host gains a catalog host operation. It validates the same disposable activation,
  builds no repository composition, model or run, and answers documentation pack requests and the
  ended-run read over the authenticated IPC session (wire 12). Imports arrive in chunks of at most
  1 MiB, and one import is staged at a time.
- The CLI's `--doc-pack-import`, `--doc-pack-list`, `--doc-pack-inspect`, `--doc-pack-delete` and
  `--doc-pack-search`, and `--ended-run`, launch only the catalog host. The harness gains `doc-pack`
  and `doc-pack-sample`.
- The Sprint 11 store producers, their tests and two documents name schema 23.
