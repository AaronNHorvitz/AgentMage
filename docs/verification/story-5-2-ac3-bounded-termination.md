Story acceptance criterion `5.2.AC3` passes for the current deterministic budget,
repeated-state, and terminal-diagnosis scope. A criterion-specific product regression reaches the
inclusive limit for parser repair, model repair, step attempts, replans, every one of the 14 closed

returns the single no-progress diagnosis. Further observations return that same sticky terminal
decision. Every terminal record forbids automatic continuation and retry, consumes no authority,
and adds zero effects.

workflow, model, tool, or provider effect. Installed-product, cross-platform, independent-review,
Story, Sprint, packaging, and release completion remain separate gates.
