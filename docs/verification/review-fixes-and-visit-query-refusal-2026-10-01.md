## Change

The review fixes:

- F1: exact decoding now re-encodes the decoded value to bytes, reads them back as JSON and
  compares the result with the frame read as JSON. The runtime writes a 32-bit number as its
  shortest decimal. Both sides now go through the same writing and reading, so a run request
  whose decoding values are `0.7`, `0.95` and `1.1` crosses the wire exactly in both directions.
  Before this fix, such a request was refused. A number written another way than the runtime
  writes it is still refused, for example `0.950000001`, or `1` for `1.0`.
- F2: the frame is read by a reader that refuses an object naming a member twice, at any depth.
  Inside a map, the types alone keep the last value. Two such positions cross the wire: the
  recipe's parameter values in a prepare request and the declared plan's. Exact decoding now
  refuses both.
- F3 and N1: the [producer contract](../architecture/runtime-producer-contract-v1.md) names the
  run request's task and the recipe's parameter values as the person's content. It also names
  the three omitted members (`recipe`, the recoverability report's `run_id` and a step's
  `suspended`), and says that an explicit `null` for one of them is refused. No fixture, record,
  encoding or version changed.
- F4: a job control decision refuses unknown members in the types. The positions that only exact
  decoding refuses are now the two tag-only ones: `shutdown` and `released`.
- N2 and the F1 claim: Decision 0135 and the
  [batch 20 record](review-fixes-and-runtime-producer-contract-2026-10-01.md) are corrected in
  place.

AMR-03.2.1 resolves residual R10 of Decision 0109. Under a task-authorized research scope, the
owner refuses a visit that carries one or more query fields as a destination error. A visit is a
request to an allowed domain other than the search provider's. Because the request is refused,
the durable reservation spends nothing and records only a clock observation, as for every refused
shape. In ask mode, each exact request is approved before it is sent, its fields included, so ask
mode is unchanged. Schema 2 scopes and plans, their bytes and their policy digests are unchanged.

Decision 0136 also adds rows AMR-03.2.2 to AMR-03.2.4 and the component row AMR-03.1.2.1. The work
selector now records 78 amendment rows.
