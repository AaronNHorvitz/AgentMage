## Verified Locally

- The extension registers the AgentMage language-model provider through the pinned stable Visual
  Studio Code API without a compiled model family or static default profile.
- The authenticated host protocol transports exact discovery snapshots and immediate selected-entry
  revalidation; missing, malformed, and tampered snapshots fail closed.
- The kernel admits no unsigned catalog projection and exposes only enabled, activated, compatible,
  policy-current, ready, supported profiles with an approved or degraded lifecycle, a passed role,
  and an explicit user decision.
- The Linux package payload includes the exact profile catalog. Startup retains a descriptor-held
  Ed25519-verified package proof, re-reads the catalog through that proof, and refuses catalog
  mutation after package verification. The current zero-enabled catalog projects only
  management-only entries.
- Candidate, evaluating, quarantined, rejected, retired, incompatible, stale, blocked, failed,
  inactive, and unsupported profiles remain management-only.
- Muse, Gemma, and an additional candidate family use the same discovery path without a family
  prerequisite.
- Exact entry revalidation binds profile, artifact, codec, tokenizer, template, runtime, context,
  decoding, hardware, policy, lifecycle, activation, compatibility, support, and limitation state.
- Removal and each tested exact-identity mutation refuse the selected entry without choosing another
  profile.
- Diagnostics, read evidence, citations, receipts, denials, cancellation, failures, and diagnostic
  export are emitted as ordered structured Chat text parts.
- Clickable file citations require the closed bounded local URI grammar; queries, fragments,
  malformed escapes, raw Unicode, oversized links, and Markdown injection are inert.
- The complete local product gate passes with all ignored live and native-platform tests remaining
  visible.

hardware observations or expose that joined snapshot through an installed native session. It also
does not connect an admitted profile to a model adapter. No production model inference, model-token
stream, exact tokenizer count, or complete context-manager integration has been exercised through
native Chat. Full task, plan,
evidence, and checkpoint preservation has not been tested through selected-profile crash,
quarantine, exhaustion, and explicit change during every request phase.

The extension has not been installed and exercised in native Visual Studio Code for this sprint.
Linux keyboard, focus, live-region, screen-reader, zoom, and reflow evidence is absent; macOS and
VoiceOver evidence is absent; the handoff preview belongs to Sprint 24; and independent Sprint 23
review is absent. Session, permission, tool, offline, and complete workspace indicators remain open.
