## Change

The review fixes change the following:

- When the host cannot read the job's phase after a decision, an applied
  resumption or cancellation withdraws the suspension, and nothing arms one.
- When a resumption or cancellation of a suspended run fails and the host no
  longer holds the run, the CLI says the host released it and ends. It no longer
  says the run continues unchanged.
- New tests isolate the withheld suspension, the check that only a continuing
  decision rebinds the driver, and the wait that never advances a suspended run.

Five AMR-05 components are new. None of them is used by a host, CLI or native
process yet.

- Routing (CAP-07): a local-only mode in which no remote route is eligible. A
  remote route also needs its own grant naming the route, candidate and
  provider, the data classes sent, an expiry, a budget and whether it may
  replace a failed route. The receipt records all of it.
- Memory (CAP-29): revocation of one item, or of every item of one workspace that
  cites a revoked source. Revoked items keep their content, are never loaded and
  stay revoked through export and import.
- Extensions (CAP-44): a signed, sequenced revocation list of packages, manifests
  and signer keys from a trusted issuer. A host refuses an older or forked list
  and a revoked package, and the catalog deactivates revoked and unchecked
  entries.
- Audit (CAP-42): a hash-chained action history of authorization, effect digest,
  outcome and evidence digests. It redacts identifiers without leaving a
  digest, keeps only the place of an expired entry, and makes a manual export
  that writes nothing.
- Support (CAP-47): a support bundle of the doctor report, component versions and
  evidence digests, published only through the existing one-use export approval
  and never uploaded.
