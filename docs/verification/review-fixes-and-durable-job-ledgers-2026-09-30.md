## Change

The review fixes change the following:

- A run resumed from an event cursor after a host restart shows its recoverability
  and context views as unavailable. The host service, the effect recorder and the
  context port each enforce this.
- The Story 23.4 boundary check refuses any use of the request in `request_tool`
  other than its parameter, one destructuring and `requested.origin`. It also refuses
  any assignment to an `origin` in the runtime loop.
- New tests cover the host service's declaration gating, the CLI's checks on
  received declarations, the IPC size refusal, the view bound and the engine's
  post-outcome accessors.
- The public line reader and the selection prompt are tested through their own
  entry points.

The operational store now keeps job control ledgers durably:

- Migration 21 adds append-only roots and entries and a forward-only head per job.
- Each append and its head commit in one transaction that names the head it read.
- Every read and every store open replays each ledger. The replay must reproduce
  every entry in canonical form and end at the head. A ledger that fails replay
  blocks the store.
- Client requests are recorded under a client scope that the owner supplies. Only
  the recorded owner can record owner observations.

No host service, IPC or CLI uses the store yet.
