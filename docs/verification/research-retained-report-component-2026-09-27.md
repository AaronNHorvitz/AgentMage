## Boundary

The existing runtime artifact owner retains only the bounded closed draft, with
private or restricted sensitivity, no preview and no effect receipt. The canonical
owner checks full sources under its existing mutex before publication and every
reconstruction. Reopening supplies current trusted clocks and independently
admitted native identities. Stored source-checked snapshots are rejected as drafts.

Generic complete reads and page reads refuse this reserved format. Ordinary-media
aliases of its complete payload digest are refused in either publication order,
including after release. These controls do not detect arbitrary copied or relabeled
derived text. Trusted composition must use the typed path. No host tool activates
that path in this increment.

Classification cannot decrease from any complete source member. Retention classes
must agree, and an expiration cannot extend any source's deadline. Session and
explicit-expiration retention are supported here; mixed classes and user holds
are refused. Source release prevents fresh reconstructed content. Physical payload
collection remains with the existing artifact lifecycle, without a new deletion
guarantee or database.

Existing payload, metadata and event ordering is preserved. The exact full
publication event must follow all source publication events. Missing, duplicate or
substituted events refuse reconstruction. A crash before event publication leaves
unreadable content. A terminal run cannot publish another draft, but later reads
may reconstruct retained evidence with current cancellation or expiry disposition.
No read dispatches an effect, refunds a reservation or resets a deadline.
