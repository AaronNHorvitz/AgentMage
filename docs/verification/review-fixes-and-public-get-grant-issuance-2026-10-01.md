## Change

Review fixes:

- F1: the authority owner commits a pending effect's terminal only when the terminal also names
  the start as its cause. An eleventh changed terminal names a real earlier event of the run, so
  only the new clause can refuse it.
- F2: the source stage builds the Linux crate's tests with the `public-research-worker` feature,
  runs its research tests and runs clippy with the feature.
- N2: Decision 0138 is corrected in place. The issuer is the engine's; the task-authorized
  issuance decision there was the test glue's.

AMR-02.2 remainder: `DurableAuthorityRuntime::issue_public_get_grant`, in a new
`research_grant.rs` submodule of the operational store, issues one exact single-use network
grant for an admitted research run. Before it commits anything:

- the budget owner checks the request without spending. The plan must not be offline. The
  packet is prepared from the retained plan and its original clock, and the issuance instant
  must fall inside the packet's interval. A visit must carry no query field under a task grant,
  and a search must use a query the plan disclosed. A dry-run reservation must pass, which also
  refuses cancellation, a spent operation and an expired or rolled-back clock. The plan must
  still be live;
- the call must match its registered tool and the packet exactly;
- the plan's mode must match the confirmation. A task-authorized plan takes the plan
  confirmation. An ask plan also takes the person's approval of the exact packet digest;
- the parent must belong to the run's session and task, and its preview must be the plan's
  digest;
- an action that already holds a grant never receives another;
- the existing issuer derives the child. Its only effect names the packet, and it expires with
  the packet or the parent, whichever comes first;
- the governing policy evaluates the exact child grant against the packet's own destination.

The parent, the child and the caller's permission event commit atomically. A refusal commits and
spends nothing, and it uses a new closed error type, so the host's exhaustive use of
`DurableAuthorityError` is unchanged. `prepare_public_get` returns the packet an ask plan
presents and records nothing. The start of a research effect now also requires its policy
network scope to name the packet's own destination.

The AMR-03.1.2.1 test glue now issues each grant through the owner.
