## Implemented boundary

The optional Linux research driver requires both existing opaque proofs: an exact
consumed grant and a fresh durable research dispatch. It reuses the existing authority
coordinator, held workspace identity, trusted clock, scoped cancellation and closed
native supervisor. The raw launch method remains private. There is no ordinary
`EffectDriver` implementation, second execution loop, database or permission issuer.

The workspace is revalidated but never projected into the connected worker. Its exact
inputs are sealed request bytes, minimal numeric resolver configuration and fixed NSS
configuration, plus pinned executable/runtime files. Host search suffixes, NSS plugins,
credentials, ambient environment, canonical store and model state are not projected.
Root-only executable/runtime trust remains unchanged. Only the two fixed systemd-resolved
resolver-data targets receive a root-delegated directory exception, with held no-follow
descriptors, exact owner/mode/type/size checks and stable complete-byte verification.

The separate syscall profile permits bounded client socket arguments while denying
other families, unknown flags/protocols, server calls, child creation and privileged
operations. It preserves the ordinary offline profile. The worker shares the parent
network namespace: this is **not OS IP/domain filtering**. Complete destination,
DNS-answer, peer and TLS mediation remains the pinned Rust worker's responsibility.
The earlier systemd IP-property canary did not establish enforcement and is not used
as admission evidence or grounds to install a privileged helper.

The original monotonic deadline includes preparation. Success requires actual exit zero,
complete bounded stdout with its full-stream digest, empty stderr, verified cleanup,
a current held root and exact parent/request/response binding. Known external disclosure
is a changed state; a possible attempt followed by failure remains uncertain, not undone
by cleanup. Original cancellation/timeout reasons remain distinct from that uncertainty.

The shared result-binding type establishes full-frame consistency only. Public constructors
cannot attest to an admitted producer. Canonical full-artifact, terminal transaction,
receipt, issued/consumed grant and runtime-event binding remains unfinished; provider
metadata or a supplied matching hash cannot become verified retrieval evidence.
