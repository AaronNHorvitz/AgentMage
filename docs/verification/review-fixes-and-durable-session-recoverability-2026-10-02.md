## Change

Review fixes:

- F1: the composed deep research run asserts that it used six turns, below its limit of 12. It
  also asserts that its artifacts fit the allowance for 12 turns but not the allowance for six.
  Decision 0142 states the fixture's limits and the reason for them.
- F2: Decision 0142's limits and the canonical research source document now describe a draft
  retained without its creation event after an interrupted completion. Every read refuses it,
  and it stays in the payload store until retention removes it.

Defect D1: preparing a run resumed after a host restart cleared the host's resume flag before
composition read it. The run's effects chain was therefore attached as if the run had continued
in the same host, and it was never marked incomplete. The restart now belongs to the prepared
run, and one function maps it to the way the run's stored chains begin.

AMR-04.7.3:

- Operational store migration 25 keeps each coding run's effect record: every executed call
  and every change record it published, with the policy revision. Each record is an
  append-only chain at a fixed position of its session. A head advances only to the record it
  names, and a closed head never changes. Every chain is replayed when the store opens.
- The tool boundary's recorder keeps each record in memory and then stores it. A store
  refusal is remembered and marks the chain incomplete.
- The factory begins the chain before the boundary exists. A new run creates it, a run
  continued in the same host attaches to it, and a run resumed after a restart marks it
  incomplete. The factory closes an unused new chain when composition fails. The service
  closes each chain at release.
- At the end of each run, the effect owner declares the recoverability of every effect of the
  session. It builds the declaration from the stored chains of every run of the session. Each
  change record is read back from the canonical artifact store as that run's own verified
  record. A session is never declared if a chain is incomplete, an earlier run was not
  released, or a record cannot be read back.
- Run declarations schema 5 carries the session declaration, over wire 16. The CLI verifies it
  as a session declaration and shows it after the run's own declaration, in both output
  formats.
- The runtime producer contract moves to version 2, with its own fixtures. Version 1 stays
  unchanged, and the current client reads it as unavailable.
- The Sprint 11 store producers name schema 25. TASKS.md gains the open row AMR-04.7.3, and
  the work selector covers 80 amendment rows.
