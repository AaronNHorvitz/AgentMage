# v1+ Assurance Boundary

The local assurance corpus exercises one closed policy shape across Visual Studio Code, CLI,
desktop, JSON, SDK, ACP, package, hook, MCP, connector, browser, schedule, and child-agent
boundaries. Each result binds an actor, current grant, precondition, terminal receipt,
cancellation, sandbox, and offline decision. Account, workspace, project, agent, worktree,
connector, and transport identities remain distinct.

Privacy cases carry only canary digests through input, output, credential, export, cache,
transcript, screenshot, and audit path classes. A passing local case requires classification,
minimization, encryption or non-persistence, retention, redaction, cleanup, and zero unauthorized
persistence or disclosure.

This contract does not establish native availability or release support for any interface. It does
not replace strict-local execution with capability packs disabled, populated-system recovery,
cross-platform results, independent review, or clean release-runner evidence. Those artifacts are
required before any corresponding lifecycle or release promotion.
