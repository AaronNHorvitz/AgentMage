## Behavior and limits

The [API and terminal guide](../guides/coding-validation.md) describes the formats.
The closed definition accepts an optional `output_format`. Absence preserves the
JSON envelope default. The selected protocol and source digest are included in
the immutable template and exact approval preview before any command executes.
Text parser identity hashes a structured pair of individual whole-file source
digests, preserving file boundaries. Caller-supplied parser digests/versions and process-exit-only test selection are
not accepted. Ordinary client credentials cannot prepare or decide executions.
The terminal shows the escaped complete preview and still requires exact typed
consent; it never chooses or approves a format for the person.

Rust stdout requires running counts, unique per-test events and matching summaries
for every complete block. Failed names carry a block ordinal to distinguish
binary-local test names. Python verbose stderr requires matching unique events,
failure/error headings, the run count and one terminal summary. Both retain the
normalizer's output hash, process termination, truncation, control-byte, secret
classification and minimum-count checks. Counters use checked arithmetic. Text
protocols reject unsupported formats and incomplete/contradictory evidence rather
than estimating results. Compiler output without a test transcript is malformed.
Measured command elapsed time remains separate from runner-reported prose.

A failure may select the existing exact prior-receipt rerun planner. Parser or
command changes cannot reset the immutable definition or spent three-attempt
budget. Every attempt still needs a fresh exact preview and consent. Dispatch
uncertainty blocks retries. Edit dispatch invalidates pending execution approval
and preserves spent attempts and the prior result as before.

These results describe the selected command's tests. They do not establish an
independent grade, current-source correctness or full-suite coverage. Approved
project test code can print forged runner output. No test output becomes tool,
model, permission or completion authority. The independent frozen evaluator is
unchanged. Model repair through the existing runtime loop, native positive
worktree/command coverage, durable run recovery/cancellation, original-repository
apply, approved commit/push, MCP and measured parent acceptance remain open.
