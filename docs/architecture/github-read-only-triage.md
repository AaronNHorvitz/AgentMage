# GitHub Read-Only Triage

Sprint 73 projects separately observed issues, pull requests, reviews, threads, checks, workflow
runs, and notifications into stable, freshness-labeled triage items. The projection binds immutable
hosted source identity, current state, base/head where applicable, edits, moved lines, permission
coverage, uncertainty, and an exact hosted-to-local repository/worktree/commit/task/decision/evidence
relationship. Missing permissions, edits, moved lines, or uncertainty make an item non-current.

Issue, pull-request, and review responses can be built only as local draft packages. Published is
always false and provider effect count is zero. Hosted text remains sensitivity-labeled untrusted
data and cannot gain authority. A separate event boundary admits only a user-initiated observation
whose signature was verified by an external approved adapter, whose delivery identity is unseen,
and whose provider timestamp is fresh. It creates no task and changes no provider state.

There is no HTTP, webhook listener, polling worker, credential, GitHub account, publication method,
or mutation operation in this module. Actual provider calls, cryptographic signature verification,
and no-mutation snapshots remain external campaigns.
