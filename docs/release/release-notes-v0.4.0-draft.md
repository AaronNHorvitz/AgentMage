# AgentMage v0.4.0 Draft Release Notes

## Publication Status

**Not released. Do not publish this document as a release announcement.**

AgentMage v0.4 is the planned bounded-coding and complete-local-CLI milestone. Local source
contracts cover nine authority-free declarative coding skills, deterministic repository mapping,
evidence-backed change planning, exact-preimage structured changes, owned worktree safety,
separately approved trusted validation, review packets, signed local-commit planning, rollback and
recovery, and thin-client command and event schemas.

The declarative skills are data, not agents or plugins. They cannot read files, invoke tools, run
commands, grant authority, access secrets or networks, change repositories, commit, publish, or
transfer work. Every change, command, and local commit remains a separate kernel transaction. Git
worktrees supplement but never replace operating-system sandboxing.

Automatic commit, push, pull-request publication, review submission, merge, release, deployment,
dependency upgrade, migration, broad refactor, arbitrary shell, network publication, frontier
handoff, and unattended write remain excluded. The current CLI has no authenticated product
transport, no coding coordinator is composed, no model profile is enabled, and no native
cross-interface workflow is claimed.

The candidate remains blocked by Sprints 41 through 49, absent product integration and parity,
missing native platform and lifecycle campaigns, missing accessibility and recovery evidence,
deferred manual fuzzing, unsigned packages, and absent independent review. No local contract,
corpus, unsigned candidate, or draft document establishes a supported release.
