# AgentMage v0.5.0 Draft Release Notes

## Publication Status

**Not released. Do not publish this document as a release announcement.**

AgentMage v0.5 is the planned manual frontier-consultation milestone. Local source contracts cover
measured task-tier recommendations, exact disclosure and redaction review, no-delivery packet
rendering, a user-initiated controlled file plan, bounded untrusted return import, artifact
quarantine, fresh local revalidation, and authority-free round-trip receipts.

The local host now composes those contracts into one restartable manual round trip. It binds the
reviewed packet, recommendation receipt, controlled export plan, and imported-result receipt in a
content-free append-only checkpoint chain, and sends returned proposals only to existing pending
local admission flows.

This design does not contain an external-model client. AgentMage does not access credentials, call
an endpoint, automate a browser, populate a clipboard, route to Codex, schedule delivery, upload
content, or import authority. The user manually moves an exactly reviewed packet and explicitly
returns result files. Imported material remains untrusted evidence and may only become a proposal
for the ordinary local review and application path.

The candidate remains blocked by upstream sprints, missing live-model and installed
prohibited-capability campaigns, missing supported-platform acceptance, incomplete lifecycle,
accessibility, privacy, and security review, deferred manual fuzzing, unsigned packages, and no
independent release decision. No source test, corpus, unsigned manifest, or draft document
establishes a supported release.
