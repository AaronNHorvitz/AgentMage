# AgentMage v0.1 Capability and Limitation Matrix

## Status Vocabulary

- **Implemented contract:** deterministic code and local tests exist.
- **Integrated locally:** the path runs through current local components with retained evidence.
- **Release verified:** supported-platform, signed-package, native, accessibility, and independent
  evidence exists. No row currently has this status.
- **Planned:** the capability belongs to a later sprint or lacks its production route.
- **Excluded:** the capability is intentionally outside v0.1.

| Capability | Current status | Release limitation |
|---|---|---|
| Kernel authority and exact grants | Implemented contract | Integrated production workflow and all-platform evidence remain open. |
| Read-only local tool catalog | Integrated locally | Native Chat complete-corpus and supported-platform acceptance remain open. |
| Git read-only inspection | Integrated locally | No Git mutation, commit, push, branch, or publication in v0.1. |
| Repository inventory and map | Implemented contract | Production native Chat composition remains open. |
| Evidence states, citations, and receipts | Implemented contract | Complete native answer composition and durable all-platform review remain open. |
| Encrypted operational state and recovery | Implemented contract | End-to-end installed workflow recovery remains open. |
| Native Linux sandbox and IPC | Integrated locally in bounded paths | Fresh Fedora and Ubuntu clean-image release acceptance remains open. |
| macOS platform boundary | Planned | No supported host, package, signing, install, M5, or accessibility evidence. |
| Windows platform boundary | Planned increment | No supported package, lifecycle, or native product workflow. |
| Exact local model lifecycle | Implemented contract | No production signed catalog or native Chat model route. |
| Native and guarded Docker inference profiles | Implemented contract | No admitted production profile; Docker remains optional and disabled. |
| VS Code model discovery and revalidation | Integrated locally with zero profiles | Signed catalog bootstrap and installed-native evidence remain open. |
| VS Code shared-runtime response streaming | Implemented contract | Deterministic fixtures stream verified events and canonical output; no installed production runtime/model route, model-token streaming, or exact tokenizer count. |
| Diagnostics and reviewed local export | Integrated locally | Supported-platform installed evidence remains open. |
| Manual Codex handoff packet | Implemented contract | Production session composition and installed-native evidence remain open. |
| Automatic Codex transfer | Excluded | No invocation, tab control, clipboard write, URI, runtime, network, or submission surface. |
| Network access in normal operation | Excluded | Acquisition is separately bounded; strict-local operation requires zero undeclared egress. |
| Workspace or repository writes | Excluded | Later grant-bearing milestones own bounded writes. |
| Shell or unrestricted CLI | Excluded | Later constrained-command milestones do not imply an unrestricted shell. |
| GitHub, CI/CD, issues, and delivery writes | Excluded | Later connected-capability milestones require separate authority and network controls. |
| Knowledge, Markdown, Obsidian, and memory | Excluded | Begins after the v0.1 gate in later milestones. |
| Email, chat, calendars, browsers, and connectors | Excluded | Later adapters require preview, approval, credentials, network, and audit boundaries. |
| Financial management and cloud observation | Excluded | Later read-only/advisory milestones; no v0.1 authority. |
| Schedules, background jobs, and child agents | Excluded | Later bounded orchestration milestones. |
| Desktop application or alternate UI | Excluded | v0.1 is native VS Code Chat first. |

No implemented-contract or integrated-locally row should be described as released until the complete
Sprint 25 gate passes.
