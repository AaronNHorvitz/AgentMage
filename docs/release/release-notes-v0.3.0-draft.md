# AgentMage v0.3.0 Draft Release Notes

## Publication Status

**Not released. Do not publish this document as a release announcement.**

AgentMage v0.3 is the planned controlled-write milestone. Local contracts cover exact-preimage
shadow changes, complete review previews, short-lived single-use write grants, fresh revalidation,
atomic application where supported, postimage verification, restoration, hash-chained receipts,
create, exact patch, copy, move, trash-first delete, structured Markdown changes, knowledge-record
creation, privacy scanning, metadata-only checkpoints, restart decisions, staging diagnostics, and
redacted state-change audit.

The capability delta is intentionally narrow. v0.3 does not add a generic shell, arbitrary process
execution, formatters or tests under a write grant, Git commit or push, remote publication,
connectors, schedules, wildcard approval, bulk knowledge reorganization, or unattended writes.
Later milestones own those capabilities under separate authority models.

The current write profile remains unregistered and effectively read-only. This candidate is
blocked by all open upstream write gates, incomplete native crash/race and live-root evidence,
missing native acceptance on every reference platform, incomplete upgrade/downgrade/restore/
uninstall evidence, deferred manual fuzzing, unsigned packages, and absent independent release
review. No local contract, unsigned candidate, or draft document should be represented as a
supported release.
