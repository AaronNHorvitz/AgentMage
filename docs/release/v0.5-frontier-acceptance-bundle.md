# AgentMage v0.5 Frontier Acceptance Bundle

## Status

**Draft and blocked. No package, external-model client, native end-to-end workflow, signing, or
release approval is asserted.**

## Bounded Candidate Scope

The proposed v0.5 delta composes local task-tier measurement, an authority-free frontier
recommendation, exact disclosure and redaction review, a no-delivery packet renderer, a
user-initiated controlled-write plan, an untrusted result-import parser, artifact quarantine,
fresh local revalidation, and a zero-effect round-trip receipt. These source contracts do not
invoke an external service. The registered host coordinator composes them without adding a client,
endpoint, credential, clipboard, browser, or network capability.

The user must move the disclosed packet outside AgentMage, choose any external tool independently,
and return a manifest and artifacts explicitly. Returned material is evidence only. It cannot
grant authority, mark work complete, run a tool, write a file, or bypass the normal local approval
and application flow.

## Acceptance Sequence

1. Measure the task against the recorded local model and policy profile.
2. Produce a recommendation containing the tier, limitations, citations, and local alternatives.
3. Render an exact packet and disclosure receipt without delivery, clipboard access, credentials,
   browser control, telemetry, or network access.
4. Require a user-initiated controlled create plan for a visible Markdown destination; reject
   stale, mutated, hidden, absolute, escaping, or colliding destinations.
5. Leave all external consultation outside AgentMage and outside the release claim.
6. Parse only the closed return-manifest grammar, verify request and artifact hashes, quarantine
   suspicious content, preserve disagreements, and reject authority or completion claims.
7. Re-establish repository, model, policy, permission, and citation facts locally before proposing
   any optional normal-flow action.
8. Emit an authority-free receipt, route any optional proposal only to pending native admission,
   and prove every prohibited delivery and gate-closure route fails.

## Cancellation and Recovery

Cancellation before export creates no file plan. Repeated export planning is deterministic and
does not write. Cancellation before import creates no receipt or authority. Repeated import of the
same exact bytes yields the same bounded analysis without applying effects. Corruption, hash drift,
state drift, or a stale local fact blocks progress and requires a new local decision. Content-free
hash-chained checkpoints retain packet, recommendation, export-plan, and import-receipt identities;
reopen rejects gaps, forks, symlinks, malformed records, tampering, and phase drift. No checkpoint
contains packet content, authority, delivery state, or an applied effect.

## Required Release Evidence

- current PASS decisions for Sprints 50 through 52 and all inherited dependencies;
- a current live-model quality, privacy, injection, and failure campaign;
- an installed whole-product prohibited-capability scan;
- clean supported-platform installation and native-interface acceptance;
- lifecycle, accessibility, privacy, retention, recovery, diagnostics, and removal campaigns;
- completed manual fuzzing and independent boundary review; and
- independently verified signed packages and a signed gate decision.

The local source evidence attached to this bundle is useful review material. It does not satisfy
the missing release evidence or close `G-V0.5`.
