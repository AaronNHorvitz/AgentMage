# AgentMage v0.1.0 Draft Release Notes

## Publication Status

**Not released. Do not publish this document as a release announcement.**

The source currently contains deterministic local contracts and partial integrations. It does not
have a signed, supported, independently reviewed v0.1 package.

Decision 0008 retains v1.0 GA as the first supported release. This v0.1 draft describes a
pre-release validation milestone only.

## Intended Offer

AgentMage v0.1 is intended to be a local-first, single-agent, explicitly selected single-model
coding harness inside native VS Code Chat. Its first release boundary is read-only and emphasizes
exact identity, deterministic authority, visible evidence, no hidden model fallback, and no network
path during normal strict-local operation.

## Candidate Capabilities

- exact model profile discovery and immediate revalidation;
- bounded read-only local tools and Git inspection;
- bounded repository inventory and source-resolvable structural maps;
- explicit evidence states, citations, receipts, diagnostics, and cancellation;
- encrypted operational state, checkpoints, backup, restore, and restart reconciliation;
- reviewed local diagnostic export; and
- reviewed local-only Codex handoff packet with manual user transfer.

Each item remains subject to its production integration and release evidence status in
[`capability-matrix.md`](capability-matrix.md).

## Required Release Evidence

Before this draft can become release notes, insert exact identifiers for:

- reviewed source revision and tree;
- signed RPM, DEB, VSIX, macOS, and other declared package artifacts;
- signer and independently distributed trust root;
- SBOM and source-to-package provenance;
- exact admitted profile and runtime;
- Fedora, Ubuntu, and MacBook Pro M5 clean-install results;
- native Chat, offline, accessibility, recovery, uninstall, and performance results;
- `RV-01` through applicable `RV-22` results;
- independent security, accessibility, platform, and release approvals; and
- support start, end, revocation, incident, patch, and rollback records.

## Mandatory Limitations

v0.1 excludes workspace and repository writes, Git mutation and publication, semantic indexing,
user knowledge and Obsidian, full CLI, desktop UI, GitHub and delivery systems, browsers, email,
chat, calendars, general connectors, financial actions, cloud changes, schedules, background jobs,
child agents, and automatic Codex transfer.

Model acquisition is separate from normal strict-local operation. No cloud fallback, hidden retry,
automatic model substitution, automatic activation, telemetry, silent update, remote kill switch,
or package-supplied trust root is permitted.

## Known Open Blockers

- production signed-catalog composition and model inference route;
- model-token streaming, exact tokenizer counting, and complete native indicators;
- production session composition for local handoff;
- installed native VS Code workflow and accessibility evidence;
- complete clean standard-user package lifecycle on every declared platform;
- MacBook Pro M5 execution, package signing, and support evidence;
- production signer and external trust-root operation;
- live workflow-specific zero-egress and complete performance evidence;
- complete incident tabletop and signed manual patch exercise;
- manual fuzz campaign assigned to Sprint 166; and
- independent release review.

Any remaining blocker keeps the release status at Not Released.
