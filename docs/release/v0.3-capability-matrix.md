| Schedules and unattended writes | Excluded | Later orchestration milestones only |

The exact planned capability delta is `workspace.write.controlled`. Its effective addition is empty:
the v0.3 write profile remains `future-disabled`, unregistered, read-only, network denied, tool
empty, and process disabled. Presence of write source modules does not enable product authority.

`G-V0.3` remains blocked until Sprints 35 through 39 pass, native write acceptance succeeds on
every declared reference platform, clean lifecycle and privacy/recovery evidence is current,
packages are independently verified and signed, and the release decision accepts all residual
risks. Local tests cannot substitute for those facts.
