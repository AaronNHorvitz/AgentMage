# AgentMage v0.5 Capability and Limitation Matrix

## Publication Status

**Not released. This matrix describes blocked local source evidence.**

| Capability | Local source status | Product and release status |
|---|---|---|
| Measured task-tier recommendation | Implemented deterministic contract and registered local coordinator | Live-model campaign absent |
| Exact disclosure and redaction review | Implemented deterministic contract | Native accessible review workflow absent |
| Local packet rendering | Registered with no delivery effect | Installed accessible workflow acceptance absent |
| User-initiated packet file planning | Controlled create plan with exact bytes and mode | Installed filesystem application evidence absent |
| External consultation | Manual user action outside AgentMage | No client, account, credential, endpoint, or automation |
| Closed return-manifest parsing | Implemented bounded parser and hash validation through the native coordinator | Installed importer acceptance absent |
| Suspicious artifact quarantine | Implemented content classification | Live adversarial and privacy campaign absent |
| Fresh local revalidation | Implemented with native task, registry, and pre-grant flow admission | Installed optional-application evidence absent |
| Round-trip receipt | Implemented zero-effect receipt with durable content-free phase recovery | Installed lifecycle/recovery campaign absent |
| Strict-local operation | No external account or service required | Installed product acceptance absent |
| Automatic upload, handoff, browser, clipboard, scheduling, or telemetry | Excluded | Must remain absent |
| Imported approval, completion, tool, write, or publication authority | Excluded | Must remain absent |
| Fedora, Ubuntu, Windows, and macOS package support | No v0.5 evidence | Clean native acceptance and signing absent |

Task tiers and recommendations communicate measured limitations; they do not silently select an
external model or broaden authority. The recommendation must include the exact local evidence,
limitations, privacy implications, and local alternatives. A user may ignore it without reducing
strict-local capability.

`G-V0.5` remains false until upstream gates pass, the live-model and installed whole-product
security/recovery campaigns pass, all supported platforms have current installed evidence, manual
fuzzing and independent review are complete, and exact packages and the decision are signed.
