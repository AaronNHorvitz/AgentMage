# Decision 0169: Native endpoint command and test coordinator boundary

| Field | Value |
| --- | --- |
| Status | Implementation detail under the accepted owner mission |
| Date | 2026-11-08 |
| Authority | Local agent mission; T-303/T-306; Decisions 0166 and 0168 |
| Scope | One original pending command or validation through the scoped tool port |

Move the original live repository owner and its prepared command or validation
into a non-cloneable endpoint handle. Require the complete sealed controlled-write
request, exact catalog, canonical proposed call, held worktree and original
creation receipt. Command memory, process and timeout ceilings must fit the
sealed run. The trusted caller retains instruction narrowing, original admission,
source consent and model disclosure responsibilities. Native-family calls refuse.

An exact protected Allow issues the original durable kernel operation grant
without launching a child or spending a validation attempt. Execution consumes
that privately retained grant through the original policy and transaction, with
fresh time, root and creation checks. Direct commands and worktree creation
continue through the same issuer/transaction path. No grant can be reconstructed
from the endpoint evaluation or a receipt. Native manifest checks precede both
issuance and dispatch; this adds no development exception or substitute executor.

Matching stages retire before dependencies. Invalid substitutions remain inert;
denial, stop, error and unwind never restore dispatch. Preserve the original
continuous control and translate matching run cancellation into the command's
original attempt-scoped signal during supervisor polling. A deadline produces a
deadline cancellation reason. Foreign or unavailable observations fail closed.
The original worker remains offline, with a read-only worktree and bounded
scratch. NotChanged reports workspace state, not absence of a process effect.

Project the actual authority receipt and original command/validation output.
Use the existing parsers, failure-feedback selection and three-attempt ceiling;
no model assertion establishes test success. Output refusal after dispatch is
uncertain; retain the process-held result and never replay. Returning the same
live repository abandons pending preview/grant handles. Issued durable grants
stay recorded until normal expiry; this is not revocation or durable recovery.

Tests use synthetic creation and command observations with actual durable grant
issuance/consumption and original parsing. A shared-coordinator fixture exercises
the original exact challenge and receipt path, then deliberately refuses upstream;
it establishes no successful native/model workflow or coding score. Controlled
startup, general model-driven edit/test/retry, recovery, approved Git and parent
measurements remain open. T-303/T-306 remain open; independent core review is
required. No row or sub-row is added or closed.
