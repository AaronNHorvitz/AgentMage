Connect the existing configured-endpoint proposal, owned-edit and validation
routes through one guided terminal command. Keep execution and all authority
inside their original API and native owners. Reuse the original controlling
terminal approvals, strict edit checker, confined command runner, test receipt
verifiers and rerun planner. Model output cannot select tests or grant an effect.

Admit the exact native test command before requesting model output. A successful
preflight is preparation only; edits invalidate pending command approvals, so
prepare each execution again. Pin the complete test template and original
worktree creation binding. Require a clean test series, at most three tests,
fresh approval per action and exact prior-receipt binding for repairs. Send each
request once and stop on a lost reply. Do not recover or renew budgets.

This is client scheduling over existing product operations, not another runtime
coordinator, model transport, sandbox, permission system or persistence format.
The retained endpoint coordinator remains read-only. Per-operation records
remain authoritative; no unified resumable run or independent grading is claimed.

Synthetic executable client tests cannot establish native model/tool success.
Native admission, autonomous endpoint edit/test composition, durable execution
recovery, approved Git, measured parent acceptance and both parent closures
remain open. No row is added or closed; independent core review is required.
