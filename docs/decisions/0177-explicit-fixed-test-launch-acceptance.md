# Decision 0177: Explicit fixed-test acceptance at development startup

| Field | Value |
| --- | --- |
| Status | Implementation detail under the accepted owner mission |
| Date | 2026-11-09 |
| Authority | Local agent mission; T-303/T-306; Decisions 0173 and 0174 |
| Scope | Private executable selection of the original-owner fixed-test checker |

Permit the existing combined development command to select
`completion_check: "fixed_test_run_v1"` in its private launch file. Absence
continues to refuse certification. The edit-only command refuses this field,
including null. Unknown choices, positional values and duplicate fields refuse.
Neither HTTP nor model output selects or replaces this checker.

Require the same single generated criterion in both original acceptance lists.
Bind the checker to the final instruction-narrowed request with its fresh
run/session identities. Check the exact fixed command, test kind, built-in
per-test text parser and positive minimum count before opening encrypted state,
inspecting native Git or reading credentials. Unsupported or additional criteria
refuse; startup never rewrites the objective or substitutes acceptance criteria.

Use the same original preview owner as edits and tests. A separate explicit
library entry point connects caller-selected acceptance checks through that
owner's borrowed evidence and pre/post source inspections before moving its
previews into the turn port. Existing generic service entry points retain their
supplied verifier. The original coordinator registry admits every candidate.

A passing candidate establishes only the declared test-run criterion. It does
not certify arbitrary task meaning, test integrity or coverage. Native admission,
continuous control, per-turn disclosure consent and each exact effect approval
remain required. Source inspection remains non-atomic. No trust exception,
permission, effect, API wire field, durable authority or automatic Git action is
introduced. Positive native/model execution and parent measurements remain open;
no row, coding model or release is qualified by selection alone.
