### L3 (low): LLVM-exception count understated

Location: `docs/evidence/t301-2-engine-inventory-2026-11-02.md:144`.
"another offers an LLVM-exception alternative" implies one package. The default
resolve has two (`rustix` 1.1.4, `linux-raw-sys` 0.12.1) and all-feature metadata
has three (adds `wasi`). Reproduce: filter `cargo metadata --locked --offline
--format-version 1` packages with a registry source whose `license` contains
`LLVM`. Fix: say "two (three with all features) offer an
`Apache-2.0 WITH LLVM-exception` alternative". It does not affect the
permissive-only conclusion.

### L4 (low): printed authority flags are literals, not derived properties

Location: `docs/evidence/t301-2-engine-inventory-2026-11-02.md:88-92`.
"registration and authority are disabled" and "with denied authority" describe
values the examples hard-code (`"authority_enabled": false`,
`SkillAuthorityCeiling::denied()`), not values computed from the manifests. The
manifests' requested scopes agree, so the claim is not false, and the section
already says the run "does not validate every output claim". Fix (backlog): say
"prints fixed denied-authority flags" so later readers do not treat them as a
checked boundary.
