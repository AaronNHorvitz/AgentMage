## Findings

### M1 (medium): eight auto-discovered example executables are absent from the inventory

Location: `docs/evidence/t301-2-engine-inventory-2026-11-02.md:17-20` and the
Binaries table (`:38-61`); method in `docs/guides/local-agent-development.md:108`.

The owner requirement (Decision 0153 item 2, row T-301.2) is to account for every
crate and binary, including what is "evidence only", so the table decides what is
carried forward. The inventory filters Cargo targets to `kind == bin` and says
auto-discovered binaries are covered, but `cargo metadata` also lists eight
auto-discovered `example` targets that `--all-targets` compiles into executables
and the fresh `cargo test` run executed (each with 0 tests):

- `agentmage-capability-knowledge`: `coding_skill_pack`,
  `document_control_skill_pack`, `executive_skill_pack`,
  `markdown_artifact_skill_pack`, `meeting_skill_pack`
- `agentmage-capability-repository-map`: `grammar_bom`
- `agentmage-kernel-engine`: `story_22_4_evidence`
- `agentmage-host`: `story_22_3_evidence`

They are live entry points: `scripts/*_skill_contract.py`,
`scripts/sprint_18_evidence.py`, `scripts/sprint_19_evidence.py` and
`scripts/story_22_3_source_preparation_evidence.py` invoke them with
`cargo run … --example`. They ship inside crates proposed for reuse
(engine, repository-map, host, knowledge), so their carry-forward disposition is
undecided, and the document's own method note ("hand-written manifest entries
alone miss auto-discovered binaries") is incomplete. Reproduce:
`cargo metadata --locked --offline --no-deps --format-version 1 | python3 -c "import json,sys;[print(p['name'],t['name']) for p in json.load(sys.stdin)['packages'] for t in p['targets'] if 'example' in t['kind']]"`;
`grep -n example docs/evidence/t301-2-engine-inventory-2026-11-02.md` returns nothing.

Fix: add an "Example executables" table (or rows) with source link, state
(these appear to be evidence/contract generators, likely scaffold or
evidence-only), evidence, and carry-forward disposition for all eight; state the
exact target kinds counted (bin, example; lib/test targets accounted by crate
counts; no bench or build-script targets exist); extend the guide's inventory
instruction and the structural comparison to include `example` targets.
