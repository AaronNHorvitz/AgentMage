## Analysis

**Authority and confinement.** The production change
(`platforms/linux/src/coding_repository_commit_review.rs:45,123-130,157-159,278`)
adds one private field. It passes the caller's original `&CancellationToken`, coerced
to `&dyn EffectCancellationObservation`, into the checker evidence.
- The trait (`kernel/engine/src/propagation.rs:152-157`) has only
  `observe_effect_cancellation`. It does not extend `Any`, so the checker cannot
  downcast to the token or reach `cancel`, `derive_child` or the node.
- The borrow lifetime is tied to the evidence. The trait's `Sync` bound makes the
  reference `Send`, which allows only scoped-thread sharing.
- The field is private and the evidence has one construction site, so no fresh or
  detached scope can be injected from outside.
- The observation is `try_lock` based. Contention gives `Unavailable`, which the doc
  requires the checker to treat as unavailable.
- If a checker ignores an observation error and returns success, the host's post-call
  `check_cancelled()` uses the blocking `is_cancelled()`. It still refuses before any
  post-check read. The host side therefore fails closed whatever the checker does.
- No new read, command, network, disclosure or effect authority is introduced.

**Failure precedence.** On `Rejected` or `Unavailable`, the existing `map_err(...)?`
returns before `check_cancelled()`. This keeps the existing codes, and the documentation
says so accurately.

**Regression quality** (`coding_repository_commit_review_tests.rs:1814-1909`).
- The zero-capacity `sync_channel` rendezvous orders the steps strictly. The worker
  first observes `Ok(None)`. Then the canceller cancels and reads `signal()`, releasing
  its locks. Only then does the worker observe again.
- The main thread is blocked in the scope join and the token is local to the test, so
  `try_lock` cannot meet contention. The race the builder described is therefore closed.
- The checks include:
  - equality of the exact signal;
  - `calls == 2`, meaning no post-check observation;
  - `checked == 1`;
  - unchanged owner inspection and validation;
