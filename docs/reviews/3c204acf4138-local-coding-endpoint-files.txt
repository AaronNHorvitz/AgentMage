## Findings

No critical, high or medium findings.

- **L1 (low, backlog).** `shells/host/src/coding_endpoint_files.rs:489-600`: no test reaches
  `CodingEndpointFiles::execute_file`, not even a synthetic one. That leaves untested:
  - sandbox take/restore
  - the `faulted` latch: set at `:516`, reset only for a non-Uncertain receipt at `:531`
  - mapping of worker error, invalid output, the sensitive-text filter and the output ceiling
  - evidence construction

  The guide's claim "An uncertain transaction or cleanup latches this boundary closed"
  (`docs/guides/runtime-endpoint-runs.md`, native-file section) is reasoned, not tested. It is disclosed
  as open, and the kernel's single-use grant independently refuses replay (probe 4), so this is low.

  Fix: move the post-receipt mapping and latch into a function taking `(receipt result, driver output,
  driver error)` and test it with synthetic receipts (Uncertain, Err, Cancelled, oversized, sensitive).
  Or add the test when native admission is available.

- **L2 (low, backlog).** `coding_endpoint_files.rs:253-260`: exclusions are matched as case-sensitive
  component prefixes before resolution. The worker's directory projection uses the same convention. On a
  case-insensitive or casefolded directory (vfat/exfat mount, ext4 `+F`), `PRIVATE/secret` resolves to the
  excluded object without matching the exclusion. Per-call exact approval still shows the spelled path,
  and Kinoite's default btrfs is case-sensitive, so this is low.

  Fix: refuse case-insensitive workspaces at selection, or resolve exclusion scopes to held directory
  identities at startup and refuse any resolution whose intermediate or final identity matches one.

- **L3 (low, inherited backlog).** `coding_endpoint_files.rs:461,473-474`: the execution-time policy
  context uses `resolved_at`, not the actual execution time. The scoped execute port carries no clock, so
  the 30-second preview expiry is not re-evaluated when the effect runs. This mirrors the original
  boundary (`linux_coding_runtime.rs:3374-3387`), and re-resolution plus worker preimage re-hashing still
  bound content drift.

  Fix: pass a trusted clock to the scoped execute path and refuse execution after
  `expires_at_epoch_ms`.

The predecessor lows (L1 zero-call binder, L2 guidance narrowing before activation) and earlier parent
lows remain open as stated. They are not re-raised.
