## Findings

No critical, high or medium findings.

**Low (backlog)**

1. **The API refusal reason is not passed to the MCP client.**
   - Location: platforms/local-api/src/coding_mcp.rs:162.
   - Every API refusal becomes `mcp.api-refused-or-disconnected`. The bounded, escaped code (for
     example `code.workspace.selection-stale` or `code.workspace.disclosure-required`) goes only to
     stderr.
   - Effect: the calling program cannot tell "relaunch with a new selection" from "the person must
     approve disclosure" or "hash stale".
   - Fix: carry the already-validated API `error` code string (pattern `^[a-z.-]{1,64}$`) in the
     isError payload. Keep `retry:false`.
2. **Invalid Request replies don't follow JSON-RPC.**
   - Location: coding_mcp.rs:93.
   - Invalid Request always replies with `id:null`, even when a valid ID is present.
   - A client-sent JSON-RPC response (`id` + `result`, no `method`) gets an error reply. JSON-RPC
     says it should get none.
   - This has no current impact because the server never sends requests.
   - Fix: echo a valid ID, and silently drop response-shaped messages.
3. **MCP staging silently replaces a person-staged pending preview, and the terminal review/apply
   display has no origin marker.**
   - Location: lib.rs:1306, and coding_cli.rs:590-610 for the display.
   - This is documented in the guide. Apply binds the displayed preview hash, so nothing undisplayed
     can be written.
   - Fix: add a staged-by field (client or terminal) to the pending preview shown at the
     controlling terminal.
4. **A control token copied as `client.token` is not detected.**
   - Location: coding_cli.rs:59-66.
   - If a person copies `control.token` into the delegated `client.token`, the bridge runs (my probe:
     exit 0) and the calling program's directory then holds the control credential.
   - The MCP tools still reach only fixed non-control routes.
   - Fix: add a one-line warning to the guide, or a launch-time probe of a control-only route
     (for example GET `/v1/settings`) that refuses if it is accepted.
