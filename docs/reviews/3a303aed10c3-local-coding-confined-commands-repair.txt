  It then raises timeout, stdout and stderr by one each, and separately uses an `EmptyScratch` spec. Each
  passes `verify()` and `CommandRegistry::build` and is refused with `code.command.bounds` specifically.
  Stale digests play no part. The renamed tampered-spec test keeps all nine original malformed cases.
- **L3 (consent fidelity): resolved.** The synthetic peer now serves a command-shaped preview: operation,
  executable identity, a non-ASCII argument containing U+03BB, U+202E (bidi override) and U+007F (DEL),
  environment and all bounds. The test checks that the transcript is ASCII-only with no raw DEL, and that
  the escaped text `\u03bb\u202e\u007f` is shown. It also parses the displayed JSON before the challenge and
  requires `consent.preview` to equal the served preview in full, plus the worktree path. The incorrect,
  approve and replace-root cases are kept, including the exact decide body on approve. The DEL code point
  is not a kernel-admissible argument (`valid_argument` rejects ASCII control bytes). U+03BB and U+202E are
  admissible, so the escaping case is realistic. The test is labelled as synthetic terminal-protocol
  evidence, which is accurate.
