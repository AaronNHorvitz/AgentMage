### L5 (low, backlog): the reporter runs only at the original absolute path

`scripts/coding_baseline_termination.py:135` combined with `relative()` at `:79-85`

The launchers record an absolute `state_directory`. If the retained campaign is restored or moved
anywhere other than its original absolute path, the reporter refuses with
`termination.records-refused`, even though every file is unchanged and the manifest digest
matches. The guide's `<private-retained-baseline-root>` placeholder suggests any root works.

- **Why it is low.** The failure is safe (a refusal) and the current retained location reproduces
  exactly.
- **A second weakness.** `main()` collapses every specific refusal code (for example
  `termination.slice-changed`) into one generic message, which makes such a refusal hard to
  diagnose.

**Fix:** if `state_directory` starts with a recorded original root, interpret it relative to
`--root`, while keeping the confinement check. Print the specific `termination.*` code on refusal.
Alternatively, document that the command needs the original location.
