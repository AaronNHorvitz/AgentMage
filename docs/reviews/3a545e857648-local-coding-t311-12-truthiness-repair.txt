### L1 (low, carried; backlog): oversize/unencodable observations crash the candidate and record `protocol`

- **Location:** unchanged from review 1, `scripts/coding_eval_oracle_worker.py:433`. `encode_message`
  runs outside the per-call `try`.
- **Reproduction:**
  - `10**5000` on dev-015 or dev-006, and `'x'*70000`, give `protocol` with candidate exit 1.
  - The same holds for NaN in a dev-029 map value, which legacy passes because NaN is truthy.
- **Status:** now disclosed in `docs/guides/coding-evaluation-oracle.md`. Every such attempt still fails
  and is counted.

### L2 (low; backlog): dev-015 container returns and over-deep dev-029 values are labelled `protocol`, though the frozen assertion accepts them

- **Location:** `scripts/coding_eval_oracle_worker.py:159-161`. `bool` accepts only `scalar_value`.
  `:179-182` caps map values at 16 levels via `observation_value`.
- **Reproduction:**
  - A dev-015 wrapper `return [1] if _orig(*a) else []` or `{'ok':1} if ... else {}` gives oracle
    `passed: false, cause: protocol`. Legacy passes.
  - A dev-029 map whose values are nested 17 deep behaves the same.
- **Why low, not medium:**
  - The guide states the transport scope exactly ("finite JSON scalars" for dev-015; "bounded to 16
    container levels" for dev-029).
  - The base `case_passed` ends in `return all(...)`, so container returns are not a natural edit of this
    predicate.
  - The result is only ever a false failure, still counted.
  - This review-1 fix recommendation was itself "finite JSON scalar".
- **Concern:** it is still a valid frame classified as malformed wire data, the same cause-label class as
  M1.
- **Fix:** accept `observation_value(result)` for `bool` (tags are already intercepted first). Or classify
  shape/depth refusals on non-policy types as a distinct fixed adapter-scope cause, and add the
  container contrast as a probe.

### L3 (low; backlog): dev-029 map keys that collide with reserved tag names are intercepted as tags

- **Location:** `scripts/coding_eval_oracle_worker.py:150-158`. Any dict result containing
  `adapter_policy` or `candidate_exception` is treated as a tag before type validation. For `bool-map`,
  the candidate's map is the top-level result, so its own keys can collide.
- **Reproduction:**
  1. Take the reference `suspend_resume_checks` result.
  2. Add `r['adapter_policy'] = True`, or `r['candidate_exception'] = True`.
  3. The oracle reports `protocol`; legacy passes.
- **Scope:** this predates this commit (the same interception existed for Boolean maps at `694808d7`). It
  needs a candidate to name a check after a reserved tag, and it can only fail the candidate.
- **Fix:** wrap `bool-map` replies (for example `{"map": {...}}`) so candidate keys never share the tag
  namespace, or disclose the reserved key names in the guide.
