## Findings

### L1 (low, backlog): `into_runtime_worktree` destroys the live owner on refusal

- **Location:** `platforms/linux/src/coding_repository_runtime.rs:26-37`. The method takes `self`
  by value. A mismatched displayed identity, or a transient `verify_created` failure, drops the
  owner.
- **Consequence:** its creation authority, held roots and any cumulative manual edit lineage are
  lost. By design they can never be rebuilt (`f.owner().into_runtime_worktree(&"0".repeat(64))`
  in the new test shows the refusal, not the loss).
- **Impact:** no file changes and the failure is closed. But a stale or mistyped consent display
  costs the person every transferable edit, while `try_into_repository` deliberately returns
  ownership intact.
- **Fix:** return `Result<LinuxCodingWorktreeLease, (LinuxCodingRepository, LinuxCodingRepositoryError)>`
  (or check through `&self` before consuming). Then add the wrong-identity-then-retry case to the
  handoff test.

### L2 (low, backlog): the host owned-write composition has no executing test

- **What is untested.** No test calls either `attach_owned_worktree`
  (`shells/host/src/coding_development_runtime.rs:475`, `shells/host/src/linux_coding_runtime.rs:837`).
  So none of these is ever executed:
  - the factory checks before prepare, refresh and composition;
  - the boundary attach check;
  - the refusal of owned writes on the legacy direct path (`linux_coding_runtime.rs:2639-2641`);
  - the ordering of `complete` after the tool-terminal commit (`:2868-2877`).
- **What I confirmed by reading.** Every one of these branches only adds a refusal or records
  lineage after the commit, so I found no defect.
- **Why it is untested.** A lease needs a live created owner, which needs native creation
  (blocked by T-301.1).
- **Wording.** The guide and the evidence Limits section disclose "no coordinator execution".
  However, evidence line 60-62 ("The native coordinator refuses an owned structured write on the
  legacy direct path…") sits in the Verification section as if observed.
- **Why it is not rated medium.** The gap is disclosed, it cannot weaken confinement, and the
  original-checkout transfer that consumes this lineage is tested and separately approved.
- **Fix:**
  - Reword that sentence as a property established by construction or code reading.
  - Once a lease can be obtained legitimately in tests, add a host boundary regression covering:
    - legacy-path refusal with the grant not consumed;
    - wrong-workspace attach refusal;
    - lineage recorded only after a successful event-path terminal commit.
