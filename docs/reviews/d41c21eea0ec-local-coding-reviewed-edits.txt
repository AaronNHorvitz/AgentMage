## Findings

No critical, high or medium findings. Low findings go to backlog, with no new rows:

- **L1 (low, test coverage)** `platforms/local-api/src/lib.rs:913-918, 968-973, 990, 1082-1085,
  1215, 1282-1285`: the new cancellation semantics have no regression test. These are the
  `cancellable` status field, `cancellation_requested:false` after dispatch, cancellation before a
  pending preview is installed, and the selection-install cancellation fix (`grep cancellable` in
  `tests/local_chat_api.rs` finds nothing). I confirmed them only by reading the single-lock critical
  section above. Fix: add API tests using a slow upstream and status polling, or a test-only pause hook.
- **L2 (low, record accuracy)** `platforms/local-api/src/lib.rs:990-1016`,
  `platforms/linux/src/coding_workspace_write.rs:290-321`: refusals that happen before the driver
  exists (expiry, root mismatch, kernel approval mismatch) are recorded after a `dispatching` record as
  `effect:"unknown"`. My P12 probe shows this: the preview expired, the file was unchanged, and the
  reply said `effect:unknown`. Expired previews also stay listed as `pending` in
  `GET /v1/code/workspace/changes` until an apply consumes them. The label is conservative, not unsafe.
  Fix: check expiry and root before `take()`, or report `LinuxCodingWriteError::Approval` as
  `effect:"none"`, and hide or drop expired pending previews on GET.
- **L3 (low, recovery documentation)** `docs/guides/coding-writes.md:115-122`: the crash guidance does
  not say that interrupted transactions can leave the driver's `.agentmage-write-*.tmp`
  temporary/reconcile files inside the workspace (`platforms/linux/src/write_transaction.rs:655, 900`).
  Fix: name them in the manual-inspection steps.
- **L4 (low, approval usability; existing renderer)** `kernel/engine/src/write_approval.rs:1191`,
  as described at `docs/guides/coding-writes.md:47`: the "complete diff" is two whole-file,
  Rust-debug-escaped strings per file, not a line diff. For files up to 128 KiB a person cannot
  practically find the change. It is not a bypass: the hashes bind exact bytes, and control and bidi
  characters are escaped. Fix: the future person-facing control should render a line diff from the exact
  pre- and postimages and recheck both hashes before showing the approve control.

The earlier lows stay as disclosed: read/proposal lease release, snapshot validation order, campaign
grade/candidate binding, and future worktree path revalidation.
