## Analysis

- **Dispatch-time checks.** `execute` (`local_commit.rs:1280-1300`) samples the host
  `RuntimeClock` first. A clock error refuses with `ApprovalDenied`. It then checks, in order:
  rollback below the construction sample, `grant_live_at(now)` (issued ≤ now, consumed ≤ now,
  now < expiry), operation = GitCommit, held object, exact argument bytes and hash, and
  `prepared.verify_at(now)` (complete packet binding plus approval window). All of this happens
  before cancellation is checked and before `executor.execute`. No branch reaches the executor
  without passing every check. Reconciliation receives the same checked `now_epoch_ms`. Nothing
  renews or replays permission: the grant was already consumed single-use by the coordinator, and
  the driver only narrows.
- **Construction.** `new` samples the clock and refuses failure (`ApprovalDenied`), verifies the
  manifest and `verify_at(now)`, and stores `constructed_at_epoch_ms`. The previous caller-supplied
  `now_epoch_ms: u64` is gone. That was the earlier low L-1 gap (a construction-time timestamp
  reused at dispatch). This change closes it.
- **Test composition.** `dispatch_commit_fixture` drives a real `GrantIssuer`, `PolicyEngine` and
  `AuthorityTransactionCoordinator::execute_effect` with a GitCommit grant bound to the prepared
  request bytes, and asserts that a consumed grant digest exists. No `EffectAuthorization` is built
  directly. `pub(crate) mod tests` remains `#[cfg(test)]`, so nothing leaks into the product API.
  The positive controls (15_000 and 19_999) launch exactly once. `driver.clock.0.is_empty()`
  proves exactly two samples, one at construction and one at dispatch. The other cases separate
  the checks:
  - approval-only expiry: 20_000 with the grant still live;
  - grant-only expiry: 30_000 with a 40_000 approval;
  - pre-consumption only: construction 10_000, dispatch 14_999.

  Packet integrity, a resealed material finding, a resealed binding change, argument mismatch and
  cancellation each refuse with zero launches.
- **Confinement.** Nothing in this change widens a boundary. No product, API, MCP or terminal
  route constructs the driver: the only call sites are in the test file. The clock is a
  host-supplied port, and there is no model- or document-controlled input to it.
- **Honesty, IP and public content.** The docs label held objects, consent and executor results as
