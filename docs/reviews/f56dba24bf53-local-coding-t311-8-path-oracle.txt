## Findings

### L1 (low): the path wire drops the return type, so the oracle accepts a result the original methods reject

The candidate side serialises `sorted(str(path) for path in result)`
(`scripts/coding_eval_oracle_worker.py:149`). The oracle rebuilds
`frozenset(Path(...))` (`:140`) after checking only string membership
(`:115-120`). The reference was wrapped to return `[str(p) for p in ...]`, which
violates the statement's `Mapping[Path,str] -> frozenset[Path]` interface. On
dev-010 it **passed the oracle** (`cause: none`, 4 calls). The unchanged legacy
grader **failed** the same source (`AttributeError: 'str' object has no attribute
'relative_to'` inside the hidden `owned()` helper). The guide says each original
method is "complete and unchanged" (`docs/guides/coding-evaluation-oracle.md:17`),
but the oracle's verdict is more lenient than those methods for this interface
clause.

This cannot be fixed by checks on the candidate side, since the candidate
controls them. It affects no current number: only frozen controls are admitted
and generated scoring is disabled. Fix before generated scoring:

- State in the guide and in the planned covered-clause labels that path-task
  return container and element types are not graded.
- Alternatively, record a separate type-check label from the frozen-controls
  path that never raises a score.

### L2 (low): candidate import failure shares the `infrastructure` cause with launch failure

`scripts/coding_eval_oracle.py:215` classifies every case without startup as
`infrastructure`. That is correct for controls (L1 of T-311.7). For future
generated attempts, though, a syntax-error edit (probe 2) is a candidate failure.
Any candidate can also choose this label by exiting before startup. If a later
scorer excluded or silently retried `infrastructure`, failures would be dropped.
Fix before generated scoring:

- Give a no-startup attempt with a launched candidate a distinct label (for
  example `candidate_startup`).
- Or specify and test that generated `infrastructure` outcomes count as failed
  attempts in the denominator.
