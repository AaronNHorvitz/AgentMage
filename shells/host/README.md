# Local Host

The Rust host composes the Phase 9 exact Linux workspace-file read. It owns the
closed request protocol, approval correlation, strict-local policy instance,
single-use grant derivation, durable authority transaction, Linux sandbox
driver, bounded UTF-8 result, citation, and receipt summary.

The host cannot construct an effect permit or approve its own request. A
product frame reaches the workflow only through a
`LinuxAuthenticatedIpcSession` already admitted by the verified Linux aggregate
and its one-use peer authenticator. The binary entry point remains inert until
Phase 11 supplies independently signed package inputs and lifecycle bootstrap.
