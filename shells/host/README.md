# Local Host

The Rust host composes the Phase 9 exact Linux workspace-file read. It owns the
closed request protocol, approval correlation, strict-local policy instance,
single-use grant derivation, durable authority transaction, Linux sandbox
driver, bounded UTF-8 result, citation, and receipt summary.

The host cannot construct an effect permit or approve its own request. A
product frame reaches the workflow only through a
`LinuxAuthenticatedIpcSession` already admitted by the verified Linux aggregate
and its one-use peer authenticator. The binary entry point remains inert until
Phase 11 supplies independently signed package inputs and lifecycle bootstrap.

The host also contains the Sprint 48 thin-client and local command contracts.
They define one closed, versioned request and hash-chained event stream shared by
native Chat, interactive CLI, JSON, SDK, and ACP-compatible surfaces. Headless
surfaces require exact predeclared single-use grants and cannot prompt, mint
authority, dispatch tools, access storage or models, or launch native effects.

The `agent` binary currently implements strict parsing, help, version, shell
completion, event rendering, and stable error exits. Operational invocations
return `client.transport.failed` with exit code `5` because authenticated product
transport and canonical command coordinators are not yet composed. See the
[thin-client boundary](../../docs/architecture/thin-client-boundary.md) and
[local CLI guide](../../docs/guides/local-command-line-interface.md).
