# Grant Review Fixtures

The `v1` fixture set is generated by the typed kernel integration test in
`kernel/engine/tests/grant_review_fixtures.rs`.

- `approval-preview.workspace-read.json` is a real `ApprovalRequest` produced by
  `render_approval_request` for one synthetic exact workspace-read proposal.
- `policy-denial.argument-mismatch.json` records the actual first-denial decision and retained
  lifecycle result after final admission observes a changed argument digest.
- `denial-receipt.argument-mismatch.json` encodes that denial in the existing shared `Receipt`
  contract and content-addresses the policy-denial fixture as decision evidence.

These are synthetic review fixtures. The approval is non-authoritative and contains none of the
nonce, use, class, or lifecycle fields required by `CapabilityGrant`. The receipt is also
non-authoritative. It demonstrates the intended shared receipt shape but does not claim that a
production receipt builder, durable hash chain, keyed integrity boundary, authenticated user
decision, isolated worker, or effect-reconciliation path exists yet.

The fixture set is locally verified against shared contracts and the Linux reference build.
macOS implementation and execution evidence remain blocked and are not represented here.
