# Contributing

Contributions are accepted under both the MIT License and the Apache License
2.0, so recipients may choose either (`MIT OR Apache-2.0`). See LICENSE-MIT and
LICENSE-APACHE. Submit only work you have the right to contribute under both.

Every commit must carry a `Signed-off-by: Name <email>` line identifying the
contributor. Use `git commit --signoff`. Follow IP-POLICY.md, AGENTS.md and the
independent review rules in TASKS.md; keep private host data out of submissions.

The licences grant no right to the project's name. Existing third-party code
and dependencies keep their own licence and attribution requirements.
